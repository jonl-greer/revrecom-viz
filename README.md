# Reversible ReCom on a 4×4 grid

Visualization of the Reversible ReCom (RevReCom) Markov chain on a 4×4 grid split
into four connected districts of four cells. 

## In this repo

```
revrecom/                 Python package: the source of truth
  grid.py                 the 4×4 grid graph (cells 0..15, row-major)
  chain.py                RevReCom, faithful to GerryChain's reversible_recom
  enumerate.py            all 117 plans, D4 orbits, dual-graph classes, cut edges, weights
  export.py               writes web/src/lib/data/plans.json
tests/                    pytest: counts, exact stationary distribution, chain validity
animation/recom_grid.py   Manim scene (video version of the grid animation)
web/                      Svelte + D3 site
  src/App.svelte          layout, controls, chain loop
  src/lib/chain.js        JS port of revrecom/chain.py
  src/lib/gridAnimator.js D3 animation of one chain step
  src/lib/histogram.js    D3 histogram: shadows, bars, falling strips, log/linear
  src/lib/data/plans.json ground truth, generated by Python (committed)
  src/lib/chain.test.js   node tests for the JS chain
.github/workflows/        tests on every push; deploy to GitHub Pages from main
```

The Python side computes the ground truth once and exports it as JSON. The browser runs its
own copy of the chain (a line-for-line port) and looks each plan up in that JSON. Both
sides are tested against the same numbers.

```bash
cd web
npm install
npm run dev        # http://localhost:5173
```
